# Building the sentence bank

`data/bank.json` is generated by `tools/build_bank.py` from open sentence collections plus the sentences in `tools/own_sentences.tsv`. Rebuild it after editing that file or changing the build rules.

```
pip install pypinyin opencc-python-reimplemented
mkdir dl && cd dl
curl -L -o hsk.jsonl https://huggingface.co/datasets/no7z/hsk-sentences-audio/resolve/main/data/train.jsonl
curl -L -o ud.conllu https://raw.githubusercontent.com/UniversalDependencies/UD_Chinese-Beginner/master/zh_beginner-ud-test.conllu
curl -L -O https://downloads.tatoeba.org/exports/per_language/cmn/cmn_sentences_detailed.tsv.bz2
curl -L -O https://downloads.tatoeba.org/exports/per_language/cmn/cmn-eng_links.tsv.bz2
curl -L -O https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2
curl -L -o cedict.gz https://www.mdbg.net/chinese/export/cedict/cedict_1_0_ts_utf-8_mdbg.txt.gz
curl -L -o complete.json https://raw.githubusercontent.com/drkameleon/complete-hsk-vocabulary/main/complete.json
cd .. && python3 tools/build_bank.py dl
```

What the build does:

- **HSK Sentences Audio** and **Chinese Grammar Wiki** sentences arrive already split into words with pinyin; their grammar point becomes the sentence's note.
- **Tatoeba** pairs are converted to simplified characters and filtered (one short sentence, no Latin text, characters within HSK 1–6), then sampled per HSK level. Word splitting and pinyin are added automatically and can contain mistakes.
- Sentences without a theme get one from keywords in the English, where one matches.
- Word meanings come from CC-CEDICT.

`tools/themes.json` must list the same themes, in the same order, as `data/themes.js`.

## Grader test set (`grader-eval/`)

`cases.json` holds 40 learner answers with a known verdict: 15 correct and
natural, 12 correct but unnatural (each with the convention it breaks) and 13
wrong. `run.mjs` sends them through the same instructions and scoring the app
uses (`js/grading.js`) and reports false alarms, missed flags, missed mistakes
and how much the result changes between repeated runs.

    OPENAI_API_KEY=... node tools/grader-eval/run.mjs gpt-6-luna 3

Run it after any change to the grading instructions or scoring. Answers the
learner disputed in the app are kept in the app's exported data under
`disputes`, and are good candidates for new cases.

## Sentence quality pass (`audit_bank.mjs`, `apply_audit.py`)

`audit_bank.mjs` sends every sentence pair in `data/bank.json` to a model, 25
at a time, and records the pairs it judges unfit for practice: fragments that
are not sentences, Chinese a native speaker would not say, garbled English,
and English that says something different from the Chinese. It is told to be
conservative. It can be stopped and restarted.

    OPENAI_API_KEY=... node tools/audit_bank.mjs gpt-6-luna
    python3 tools/apply_audit.py

`apply_audit.py` removes the rejected pairs from `data/bank.json` and lists
them, with the reason for each, in `bank_rejected.tsv`. `build_bank.py` reads
that file, so a rebuild leaves the same pairs out. To put a pair back, delete
its line and rebuild.
